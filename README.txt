PITO PAKEETO WEBSITE — MAC / GITHUB PAGES GUIDE

This folder is ready to upload.

FILES
- index.html — the website
- PitoWebsite.png — the exact flyer image shown on the website
- PitoWebsite.pdf — the original downloadable PDF

Keep all three files together and do not rename them.

UPLOAD TO GITHUB PAGES
1. Go to https://github.com and create a free account.
2. Click the + button at the top-right.
3. Click New repository.
4. Name it: pitopakeeto-website
5. Choose Public.
6. Click Create repository.
7. Click “uploading an existing file.”
8. Drag index.html, PitoWebsite.png, and PitoWebsite.pdf into the upload box.
9. Click Commit changes.
10. Click Settings in the repository.
11. Click Pages in the left column.
12. Under Build and deployment, choose “Deploy from a branch.”
13. Choose branch “main” and folder “/ (root).”
14. Click Save.
15. Wait a few minutes for GitHub to display your temporary website address.

The website keeps the exact digital-flyer appearance. The YouTube, Spotify,
and booking areas remain clickable. It also includes Open PDF and Download PDF.
